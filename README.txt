PUBLISH ON GITHUB PAGES
1. Sign in to GitHub and create a new public repository. For a main personal site, the repository can be named username.github.io (replace username with your GitHub username).
2. Upload index.html, style.css, script.js, README.txt AND the entire assets folder, preserving the folder structure. IMPORTANT: the QR and profile photo are stored in assets; uploading only the three code files will make images disappear. Keep the folder name exactly assets and the QR filename exactly whatsapp-qr.jpg (all lowercase).
3. If using a regular repository instead, open Settings > Pages and select Deploy from a branch, choose main and /(root), then Save.
4. Wait for GitHub Pages to publish the site. The address appears in Settings > Pages.
